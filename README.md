# Smart---Document---RAG

Cài đặt thư viện: pip install streamlit langchain-community langchain-text-splitters pdfplumber docx2txt

Trong đó:
- pdfplumber: đọc nội dung PDF.
- docx2txt: trích xuất văn bản từ file DOCX.
- langchain-community: cung cấp các Document Loader.
- langchain-text-splitters: chia văn bản thành chunks.
